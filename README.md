# 🛠️ Multi-Utility Toolkit

## 📌 Project Description
The Multi-Utility Toolkit is a Python-based project that provides multiple useful functions through a simple menu-driven program. It uses built-in Python modules and a separate toolkit module to perform different operations.

## ✨ Features
- **Date & Time:** Displays the current date and time.
- **Math Operations:** Calculates the square root and factorial of a number.
- **Random Password Generator:** Generates an 8-character random password.
- **UUID Generator:** Creates a unique identifier.
- **Save File:** Saves user-entered text into a file named `output.txt`.
- **Explore Module:** Displays available attributes and functions of the random module.
- **Exit:** Closes the program.

## 🧰 Technologies Used
- Python 3
- datetime module
- time module
- math module
- random module
- uuid module
- File Handling
- User-Defined Functions

## ▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Keep `main.py` and `toolkit.py` in the same project folder.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

6. Select an option from the menu.
7. Follow the instructions displayed on the screen.
